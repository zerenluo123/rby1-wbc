# G1-D WholeBodyIK 这一版

只适用于 **G1-D**，配置在 `config/wbik_g1d_hardgate.yaml`（原来的 `wbik_g1d.yaml` 改名而来，内容不变）。RBY1（`wbik.yaml`）和 R1 Pro（`wbik_r1pro.yaml`）没有按这套改。

本文描述的是**硬门**方案。替代它的**影子门**方案在 `config/wbik_g1d_shadowgate.yaml`，两份 yaml 除了门那一段以外完全一样。对应的求解器在本仓库 `solver/`（`hard_gate_ik.py`、`shadow_gate_ik.py`）；拖球预览用 `scripts/g1d_wbik_gui.py --gate hard|shadow`，Quest 轨迹回放对比用 WholeBodyControl 仓库的 `Hommi_WBC/replay_quest_new.py --gate hard|shadow`。影子门的来龙去脉见 `config/G1D_WBIK_ISSUES.md` 第 1 条。

控制器只吃两只手的目标位姿。`dt = 0.05 s`。腰的点头轴是 `Yaw_Joint`（绕 Y，范围约 −2.5° 到 135°）。

回放：

```bash
.venv/bin/python Hommi_WBC/replay_quest.py --robot g1d --dt 0.05 --viser
```

Viser 里 **Yaw door → Show yellow door plane** 默认不勾。勾上才画黄平面：世界高度 `z = 1.00 m`，跟底盘走，用来看手的目标有没有穿过弹簧门。

## 最终留在 G1-D 上的参数

| 项 | 值 | 作用 |
|---|---|---|
| `com_over_base_pos_cost` | `0` | 关掉软「胸在底盘上方」。硬框 `±8 cm` 还在 |
| `ee_ori_cost` | `2000` | 手朝向。不再用 10000 |
| `ee_ori_exclude_joints` | `Yaw_Joint` | 朝向雅可比不驱动点头。位置还能驱动 |
| `yaw_upright_z_ref` | `1.00` m | 两只手目标里较低的那只 `z` |
| `yaw_upright_gate_eps` | `0` | 硬门：`z ≥ 1.00` 弹簧满开，低于就关 |
| `yaw_upright_cost` | `4000` / 关时 `0` | 把点头拉向 `0` |
| `yaw_upright_error_clip` | `0.034906585` rad（2°） | 弹簧每帧最多消 2°，打开时不顶满速度盒 |
| `ee_lm_damping` | `0.5` | 站立、手还能跟上的段（约 247）不再来回抖 |

速度盒没改：`Yaw` 每帧最多约 `0.9 × π × 0.05 ≈ 8.1°`。真弯腰用到的大约是 5–6°/帧，没有把这个盒子收紧。

## 这些改动是怎么定下来的

### 1. `com_over_base_pos_cost` 其实是 `ν_xy`，只在 `R = I` 时才是水平距离

名字像「质心不要偏出底盘」。实现是 Mink 的 `RelativeFrameTask`：胸系相对底盘的 SE3 对数的前三维，再乘 `position_cost`。那三维是

\[
\nu = V(\omega)^{-1} p
\]

不是胸口原点的水平坐标 `p_xy`。只有相对旋转 `R = I`（`ω = 0`）时，`ν_xy = p_xy`。

RBY1 先把这件事保证了，软任务才碰巧等于「原点水平距离」：

- `torso_0`、`torso_4`、`torso_5` 锁在 0
- 等式 `torso_3 + torso_1 + torso_2 = 0`，也就是 `q3 = -(q1+q2)`，胸系转不起来

R1 Pro / G1-D 把点头放开以后 `R ≠ I`，同一条任务不再表示 `p_xy`，点头会被 `ν_x` 拽住。G1-D 的胸锚又改到了点头轴 `Yaw_Link` 上，这个点的真实 XY 几乎不随点头变。软项留着没有正事，只挡弯腰。

所以 G1-D 把顶层 `com_over_base_pos_cost` 设成 `0`，软任务不进 QP。`legacy` 里的 `10` 在 `use_ik_adjustment: true` 时不读。硬框 `com_over_base_xy_bounds: [0.08, 0.08]` 用的是真实笛卡尔差，点头进不去，留着。

### 2. 朝向不能再推点头

手朝向和位置一样重的时候，点头会把两只手的坐标系一起转过大约同一个角度。QP 宁可手够低、也不肯点头把朝向一起毁掉。这和 RBY1 用关节等式把肩线钉平是同一类效果，只是写在任务里。

G1-D 做了两截，都只动 `Yaw_Joint`：

1. **朝向列清零。** `ee_ori_exclude_joints: [Yaw_Joint]` 把末端朝向雅可比在点头上的列设成 0。朝向不再点头。位置项还能点头，所以够低的手仍然可以弯腰。`ee_ori_cost` 固定在 `2000`。
2. **直立弹簧。** 位置项在站直、手已经够得着的时候仍会选一个大点头（247、845：锁死 `Yaw=0` 时手误差只有一两厘米，自由解却会弯到二十多度）。弹簧把 `Yaw` 拉向 0，权重由手目标高度开关：较低的那只手 `z ≥ 1.00 m` 时权重 `4000`，否则 `0`。83、134 那种手在 0.4 m 附近的真弯腰在门下，弹簧是关的。

中间丢掉的做法：

- 高度上漏一点弹簧（手在 0.4 m 时权重还剩大约 400）。肩被抬高，腕靠近奇异，弯腰段来回抖。
- 在 1.10 m 下面做几厘米线性过渡，或用 1.05 / 1.15 滞回。手一行就穿过那一条缝，抽动只是换了高度。
- 用位置对点头的方向导数 `g` 决定要不要开弹簧。跟踪完成以后真弯腰和假弯腰的 `g` 都接近 0，不能当判据。
- 全局手臂粘滞、饱和锁存、弯腰增益。会把跟得上的朝向粘死。
- 把弹簧目标改成「最小够得着的点头角」。那个角落在手臂伸直的边界上，真弯腰会被挤向奇异。

门本身仍是阶跃。打开时如果腰上还留着十几度，一帧把整个角度误差塞进 QP，速度盒会顶满 ±8.1°，肩大约动 5 cm，手的朝向误差跟着跳（464 在没有裁剪时朝向从 2° 跳到 7.5°）。裁剪只加在弹簧自己的误差上：`|q_Yaw| > 2°` 时这一帧只要求收回 2°。464 变成每帧 −2°，位置误差保持 0，大约 0.45 s 回到直立。站直段（247、845）腰已经在 2° 以内，裁剪不改变按住的力。

弹簧**关掉**的那一帧不在这次裁剪里。手从门上掉下去时，位置项可能在一帧里把点头顶向速度盒。

### 3. `ee_lm_damping = 0.5`

Mink 默认大约 `1e-5`。手目标不可行时（左右分开大约 1.4 m，位置误差十几厘米），手臂零空间会一帧一个构型，正负顶满。

阻尼加在手任务的 Hessian 上：`μ = ee_lm_damping · ||W e||²`。误差大时，这一帧更不愿意大步改关节。

- `0.3`：800 帧以后那种张开抖动能压住，但 247–254 手臂仍有大约 50 次「相邻两帧反号、且两边都超过 2°」。
- `0.5`：247 那段反号剩下 1 次。83 / 134 的真弯腰还在（大约 77° / 89°，手误差接近 0）。
- `1.0`：247 也不反号，但大偏差之后更难把解算回来。

固定 `0.5`。代价是：误差到几十厘米时 `μ` 很大，daqp 经常直接返回没有解。代码这时保持上一帧姿态、速度写 0。手的目标还在动，看起来就是身体卡住。`0.3` 在 loco_9 上大约 896 帧、误差还有 18 cm 时就能重新解出来；`0.5` 要到手再近一些（大约 909）才恢复。

## SOP

### 这一版能覆盖的

- 双手目标在身体附近，较低的手可以低于 `1.00 m`。弹簧关掉，允许点头去够。loco_9 里 83、134 就是这种。
- 人站着、两手高度在 `1.00 m` 以上、左右分开还在手臂够得着的范围里。弹簧把点头按在 0° 附近。247 的手误差大约还有 1–4 cm、朝向大约 2°，但不再来回折。
- 手的目标穿过 `1.00 m` 往上走、腰上还留着弯腰角。弹簧每帧最多收 2°，不要期望一帧站直。

黄平面就是这道 `1.00 m`。比的是**目标手**的高度（两只里较低的），不是机器人当前手的高度。

### 不要拿这一版去跟的

- **loco_9 大约 800 帧以后那种大张臂。** 左右手水平距离到大约 `1.4–1.5 m`，两臂够不到（大约 1.1 m 量级）。点头几乎不改变左右分开的距离。位置误差会停在十几厘米。
- 这段里求解器会整段返回没有解。机器人停在进入这段之前的姿态，直到目标自己靠回来。不要把这段卡住的姿态当成「跟上了」，也不要在策略里把这种张臂当成 G1-D 的正常工作区。
- 不要为了让这段也动起来把 `ee_lm_damping` 调回 `1e-5`（247 会再抖），或调到 `1.0`（大偏差之后卡得更久）。

### 改参数时不要动的边界

- 不要把 `com_over_base_pos_cost` 设回 RBY1 的 `100000`。那条任务在点头放开后不是水平距离。
- 不要去掉 `ee_ori_exclude_joints` 里的 `Yaw_Joint`，也不要把 `ee_ori_cost` 调回 `10000`。朝向会再去点头。
- 不要把 `yaw_upright_z_ref` 当成臂展边界。`1.00 m` 是站立工作区的门，用来别在够得着的时候假弯腰。真弯腰靠门下弹簧为 0。
- 不要把 `yaw_upright_error_clip` 拿掉。拿掉之后，过门打开的那一帧会回到 ±8.1° 的抽，手误差跟着跳。
- RBY1 / R1 Pro 的 yaml 和黄金回归不要跟着 G1-D 改。它们的胸系仍然靠锁关节维持 `R = I`。
